# Sidtisak Hanthongchai — Personal Portfolio & Resume

เว็บไซต์ Personal Portfolio และ Resume สำหรับแนะนำตัว นำเสนอทักษะ ประสบการณ์ และผลงาน สำหรับการสมัครงานและยื่นฝึกงาน/สหกิจศึกษา (Cooperative Education)

---

## 🌟 จุดเด่นของเว็บไซต์ (Features)
- **Single-Page Landing Page**: โครงสร้างหน้าเดียวยาว ใช้งานง่าย เลื่อนลื่นไหล (Smooth Scroll)
- **Dark / Light Mode**: รองรับทั้งโหมดมืดและสว่าง พร้อมจำค่าที่ผู้ใช้เลือกผ่าน `localStorage`
- **Responsive Mobile-First**: รองรับการแสดงผลบนหน้าจอทุกขนาด (Mobile, Tablet, Desktop)
- **Micro-interactions & 3D Parallax**: เอฟเฟกต์ Floating elements, Glow card และ Cursor effect ที่ลื่นไหล
- **Clean Tech Stack**: เปิดไฟล์ใช้งานได้ทันทีโดยไม่ต้องรัน Build Server

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5**: Semantic tags ถูกต้องตามมาตรฐาน Accessibility
- **Tailwind CSS (CDN)**: ระบบ Utility-first CSS สำหรับ Layout และ Style
- **Vanilla JavaScript**: ควบคุม Dark Mode, Mobile Hamburger Menu, Smooth Scroll
- **AOS (Animate On Scroll)**: เพิ่มการเคลื่อนไหวเมื่อเลื่อนหน้าจอ
